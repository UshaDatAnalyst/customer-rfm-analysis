# Customer RFM Analysis Project

## Overview

This project performs RFM (Recency, Frequency, Monetary) Analysis using customer transaction data.

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Data Cleaning
* Recency Analysis
* Frequency Analysis
* Monetary Value Analysis
* Customer Segmentation
* RFM Scoring
* Data Visualization

## Key Insights

* Identified high-value customers.
* Segmented loyal and inactive customers.
* Analyzed customer purchasing behavior.

## Project Files

* `customer_rfm_analysis.ipynb`
* `Online_retail.xlsx`
